SidebarSectionsectionId名称、类型、顺序包含 SectionEntry只改变左侧栏组织方式

05

关键业务规则

这些规则解释了最常见的导航与工作目录问题。

R1 · 分组与执行解耦

移动项目或任务到自定义分组，只更新导航引用和顺序，不修改项目路径、任务绑定或磁盘内容。

R2 · 新任务继承项目环境

从项目入口创建任务时，项目路径和主机用于建立任务的默认 Workspace 与 CWD。

R3 · 既有任务保留 CWD

任务创建后保留自身执行目录。重启应用、置顶、归档或改变分组不会自动重新绑定。

R4 · 项目不等于 Git 仓库

项目可以是普通目录；Git 仓库既可以位于项目根目录，也可以是项目目录下的一个子目录。

R5 · Worktree 用于隔离

Git 项目可派生独立 Worktree，为并行任务提供隔离的分支和文件修改空间。

R6 · 任务大于普通对话

Codex 任务不仅包含消息，还承载工具调用、命令执行、文件变更、产物和运行状态。

@startuml
title Codex 核心数据对象关系模型

class SidebarSection {
  +sectionId: UUID
  +name: String
  +sectionType: SectionType
  +displayOrder: Integer
}

class SectionEntry {
  +targetType: TargetType
  +targetId: String
  +displayOrder: Integer
}

class Project {
  +projectId: String
  +label: String
  +path: AbsolutePath
  +hostId: String
  +isGitRepository: Boolean
}

abstract class Thread {
  +threadId: UUID
  +title: String
  +summary: String
  +kind: ThreadKind
  +status: ThreadStatus
  +updatedAt: DateTime
}

class CodexTask {
  +projectId: String [0..1]
  +hostId: String
  +cwd: AbsolutePath
  +model: String
  +reasoningEffort: String
}

class ChatConversation
class Folder { +path: AbsolutePath }
class Workspace { +environmentType: EnvironmentType }
class GitRepository { +rootPath + remoteUrl + branch + headCommit + dirty }
class GitWorktree { +path + branch + baseRevision + status }
class Turn { +sequence + status + timestamps }
class Message { +role + content + createdAt }
class ToolCall { +toolName + arguments + status }
class FileChange { +path + changeType + timestamp }
class Artifact { +type + path + createdAt }
